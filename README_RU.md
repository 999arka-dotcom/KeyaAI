# KeyaAI — стартовый Android-проект

## Что уже реализовано
- Android-приложение на Kotlin + Jetpack Compose.
- Создание новых чатов.
- Переключение между сохранёнными чатами.
- Удаление чатов.
- Автоматическое сохранение истории на устройстве.
- Выбор изображений, видео и некоторых файлов через системный выбор файлов.
- Сохранение URI вложения в истории чата.

## Важно: это стартовый прототип, а не готовый универсальный ИИ
Движок языковой модели ещё не встроен. Сейчас приложение честно показывает, что модель не подключена, вместо того чтобы выдавать фиктивные ответы за ответы ИИ. Анализ фото/видео и интернет-поиск тоже требуют подключения отдельных модулей.

## Как собрать APK
1. Установи Android Studio на компьютер.
2. Открой папку `KeyaAI_Android_Project` в Android Studio.
3. Дождись синхронизации Gradle. Если предложит установить Android SDK 35, согласись.
4. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Следующий шаг — подключить настоящую локальную модель
Для этого нужно подобрать runtime и квантованную модель, совместимую с телефоном. Нужны модель телефона, объём RAM и свободное место. Маленькая модель может работать на устройстве, но скорость и качество будут зависеть от железа.

## Ограничения текущей версии
- Хранилище использует SharedPreferences/JSON и подходит только для прототипа; для больших историй лучше Room.
- Вложения сохраняются как URI, а не копируются внутрь приложения.
- Вложения пока не отправляются в модель на анализ.
- Интернет-поиск пока не подключён.
- Для установки на телефон нужно собрать APK в Android Studio.

## Сборка APK с телефона через GitHub Actions
В проект добавлен workflow `.github/workflows/android.yml`.
1. Создай репозиторий на GitHub в браузере телефона.
2. Загрузи туда все файлы проекта, включая папку `.github/workflows`.
3. Открой вкладку **Actions** и разреши выполнение workflows, если GitHub попросит.
4. Запусти **Build KeyaAI APK** через **Run workflow** (или дождись сборки после push в `main`).
5. Открой завершившийся запуск, найди раздел **Artifacts** и скачай `KeyaAI-debug-apk`.
6. Распакуй скачанный ZIP-архив артефакта и установи `app-debug.apk`.

Примечание: это debug APK для тестирования. Он не подписан релизным ключом для публикации в Google Play.
